# Лабиринт (Labyrinth)

Веб-прототип игры «Лабиринт» (бумажная игра): исследование скрытого лабиринта на клетчатом поле, поиск клада и выход с ним.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Механики

- Скрытое поле генерируется по seed; игрок видит только ответы ведущего.
- Перемещение по 4 направлениям, стены блокируют ход.
- Ямы телепортируют в парную яму и начинают новый фрагмент карты.
- Клад подбирается кнопкой; выход с кладом завершает партию (настоящий/ложный клад раскрывается при выходе).
- Блокнот картографа: фрагменты можно накладывать призрачным слоем, двигать по сетке, закреплять как гипотезу.
- Генерация по seed, перезапуск новой карты.

## Стек

React + TypeScript + Vite. Ассеты сгенерированы (image_generate).
